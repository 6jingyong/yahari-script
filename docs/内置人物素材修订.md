生成模式为 **内置 image_gen**，每名角色单独生成一个八动作页；未使用本机 OpenRouter Key 或 ChatGPT 登录桥来画图。正式源图保存于 `content-packs/courtroom-demo/art-source/<id>-actions.png`，头像为同目录 `<id>-portrait.png`；发行 WebP 保存于 `content-packs/courtroom-demo/assets/chibi-<id>-actions.webp` 和 `chibi-<id>-neutral.webp`。完整提示词、生成文件编号和源图哈希保存于 [halfbody-20261013.json](../content-packs/courtroom-demo/art-source/halfbody-20261013.json)。更新前文件在本机忽略目录 `work/art-20261013/before/` 留有备份。

源图保留透明通道；构建只做分格裁切、等比缩放与透明画布布局。发行 WebP 使用 `quality=88, method=6`，保持尺寸和 alpha；从页面提取、修改和导出时仍按 [默认图片压缩规则](素材制作与格式说明.md) 处理。
