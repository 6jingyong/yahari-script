# 作品文件、保存与恢复

更新：2026-10-14，当前本地版本。旧「目录」入口已由顶栏「作品管理」取代；其中「作品与文件」继续管理本机作品和恢复点。作品管理中的表单需要保存，Ctrl+S / 顶栏保存也会先保存这些资料再执行既有文件保存流程。

分支作品使用 0.9 格式；旧 0.7 / 0.8 仍可导入，JSON 与 .yahari 均保留路线。另可从作品管理「导出独立 HTML」分享可离线游玩的文件。见 [作品管理与分支剧本](BRANCHING_STORIES.md)。

## 使用

- **自动保存**：编辑台词约 300 ms 后保存；添加动作、切换场景等操作立即提交保存。顶栏显示保存中、保存时间或失败。下一次打开恢复作品及上次编辑的场景。
- **保存 / Ctrl+S**：保存当前作品并建立恢复点。若本次打开期间已选择文件，也更新该文件。
- **目录 → 作品与文件**：查看、打开多个本机作品，恢复当前作品最近 8 个保存点。删除本机副本前有确认，当前作品不提供删除按钮。
- **保存到文件…**：支持文件选择器的浏览器允许选择磁盘上的 `.yahari` 文件。本次页面会记住文件位置；刷新后需重新选择。其他浏览器直接下载作品包。
- **导出项目 / 下载 .yahari 备份**：下载包括全部场景、人物绑定与自有图片的作品包。内置主题包仍由编辑器提供，文件保留它的版本引用。
- **导出兼容 JSON**：保留 `.yahari-project.json`，原创图片以内嵌 data URL 保存，便于旧格式工作流或查看内容。
- **导入项目**：接受 `.yahari`、旧 `.yahari-project.json` 和旧裸文档 JSON。先预览名称、章节、场景、人物和图片数，再点击“导入并打开”。导入会保存当前作品；若本机已有相同作品 ID，会建立副本。

作品库属于当前浏览器、当前站点地址。换设备、换浏览器或换端口时使用作品文件迁移；清除网站数据会移除本机作品库和 AI 连接，不会删除已经保存到磁盘的作品文件。未发送的台词仍是本机输入草稿，不计入导出的正式剧本。

角色与场景原件使用独立素材库，角色包/场景包可单独导入导出；加入作品后复制为作品自有素材，由本页所述作品文件一起保存。详见 [素材库](ASSET_WORKSPACE.md)。

## 保存边界

本机使用 IndexedDB 的 `projects / assets / revisions / settings` 四类存储。图片以 SHA-256 标识的 Blob 单独保存，相同图片复用；项目与恢复点只存引用。项目、图片、当前作品指针和恢复点在同一事务提交。请求失败或中途抛错会回滚，保存完成才显示成功。

自动保存更新最新记录；手动保存和作品切换建立恢复点，最多 8 个。删除恢复点/作品时回收没有任何作品或恢复点引用的图片。切换编辑场景只改变本机浏览位置，保持作品的 `entryDocumentId` 不变。

首次启动会尝试迁移旧浏览器草稿，成功后仍保留旧源数据；IndexedDB 不可用时继续使用原浏览器草稿保存方式，并提示导出备份。读取失败的现有数据库不会在启动时被旧草稿自动覆盖。保存未完成或失败时，离开页面会触发浏览器的未保存提示。

AI Key 与模型连接配置继续独立保存；不属于作品库、恢复点或作品文件。

## 文件契约

`.yahari` 是版本 1 的 ZIP STORE 容器，内含 `project.json` 和可选 `assets/0001.webp` 等二进制图片。WebP/JPEG 已压缩，因此容器直接保存这些字节。相同图片在容器内只存一次；导入重建可移植项目后，仍经过 Core 结构/身份校验及素材包校验。

- 校验 ZIP 目录、路径、条目唯一性、大小、CRC、图片引用以及未引用条目。
- 拒绝缺图、损坏、路径穿越、不支持的压缩/文件版本，且不激活当前作品。
- 文件最大 32 MB。当前 0.8 项目格式仍限 4 个嵌入包、每包 100 张图片、总计 20,000,000 个图片 data URL 字符；二进制导入也限制展开后的图片总量。
- 支持 JSON 0.7/0.8、UTF-8 BOM 及旧裸文档显式绑定。
- 缺少适配器/主题包时可以只读打开并再导出；修复性语义错误仍保留。
- 本轮只接受本编辑器生成的 ZIP STORE 作品包，普通 ZIP 压缩文件不能直接作为作品导入。

## 验收证据

使用 OpenRouter 免费模型生成三份原创中文短剧本：6 场、40 句。三份成功结果为 3,677 token，费用均报告为 0；成功 token 统计不包含失败/重试请求。曾遇到截断与不完整 JSON，未通过校验的输出没有成为作品。

浏览器实测完成 JSON 导入预览、场景切换、排练、`.yahari`/JSON 导出、刷新恢复、恢复点回退和新浏览器作品包导入。逐字段比对三份真实导出包与模型源作品，人物/章节/场景/开场引用和编译结果一致。另验证原创角色及背景的 Blob 保存和文件携带、同 ID 副本导入、损坏包不替换作品、保存中途失败回滚、8 个恢复点上限、旧草稿迁移及数据库不可用时的兼容保存。

文件下载使用真实浏览器下载验证；文件写入/关闭和后续 Ctrl+S 使用模拟的系统文件选择器验证，尚未自动操作 Windows 的原生另存为窗口。实机手机交互尚待验收。

示例入口：[OpenRouter 生成剧本](../examples/openrouter-scripts/README.md)。运行 `npm run check` 会检查单元测试、模块与素材，并验证三份真实导出包的结构和编译一致性。
