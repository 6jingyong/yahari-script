# 素材管理：角色、场景与声音

更新：2026-10-14。GitHub Pages、GPT Sites 和本地版均已更新。制作规则见 [素材制作、尺寸与默认压缩](素材制作与格式说明.md)。

## 使用

顶栏的 **对话编辑 / 素材管理** 切换两个独立界面。素材管理包含角色、场景、声音和素材包四个分类，可以按名称、设定、说明或标签搜索，筛选内置及其调整、原创 / 导入素材。

内置 24 个角色、192 个动作、23 个场景自动显示，可编辑、增补、移除与恢复默认；不需要逐个导入。角色舞台背景和透明前景、场景前景也可以上传或移除。动作从内置图集按真实裁切框提取为独立图片，保留原角色 / 动作 ID；编辑后的默认动作及新增动作都可在对话和排练中使用。

- **角色**：新建或编辑姓名、人物设定、标签和立绘；上传图片，也可使用共用 OpenRouter 连接选择绘图模型生成。动作支持增加、改名、替换图片、改变类别和删除。至少保留一个姿态动作；第一次保存自动补充“平常”。参考生成会发送当前立绘，所选模型需支持参考图。
- **场景**：新建或编辑背景图片、名称、说明与标签。支持上传或 OpenRouter 图片生成；生成背景不请求透明底。
- **保存到素材库**：仅保存素材原件，不改变作品。编辑素材需要明确保存，Ctrl+S 保存当前素材或包资料；切换分类时提醒未保存修改。
- **加入当前作品 / 应用到当前场景**：复制所选素材包到作品；角色加入人物列表，场景应用到当前编辑场景。作品中的图片副本随作品文件携带。再次使用同一包更新已有副本，保留人物绑定与动作 ID；仍被剧本引用的人物、动作或场景不能被删除后覆盖。
- **收录当前作品素材**：把旧作品中的自有图片角色与背景保存到独立素材库。保留原有角色、动作和图片 ID；内置主题包不复制。
- **素材包资料**：包名、版本、作者、来源、许可和说明。默认许可为“未声明”。这些记录随素材包和作品副本保留；独立导出不改变素材的实际使用权。
- **删除本机包 / 素材**：删除素材库原件；已经加入作品的副本保留。
- **内置移除 / 恢复**：移除会持久隐藏本机列表中的素材，可恢复且保留此前调整；恢复默认会清除本机调整，已有作品保留自己的版本。
- **人物喊话**：声音类型中选择「人物喊话」，可试听 / 下载 17 段内置日语录音，并在对话动作详情中绑定或静音。声音跟随所选视觉人物，支持单次覆盖与人物默认；离线 HTML 包含录音。详情见 [动作声音](ACTION_SOUNDS.md)。
- **声音**：35 个原创 8Bit 音效与 16 段循环配乐，按界面、对白、法庭、证物、转场、调查、询问、推理、回忆、收束等用途分类；设置常驻侧栏。支持使用说明、音色、相对音量 / 速度、新增、试听、移除 / 恢复、8-bit WAV 下载和 JSON 参数包。明确应用后随作品导出；应用时保护剧本仍引用的声音。详情见 [8Bit 声音](8BIT_AUDIO.md)。

原件属于当前浏览器和站点地址，可跨本机作品复用。更换浏览器、端口或设备时导出迁移；清除网站数据会移除原件，磁盘导出文件保留。素材库保存失败会显示原因并保留编辑草稿。

## 独立包导入与导出

| 文件 | 内容 |
| --- | --- |
| `.yahari-characters` | 角色设定、标签、立绘、姿态与表情、可选舞台背景 / 前景、来源许可 |
| `.yahari-scenes` | 场景说明、标签、背景、可选前景、来源许可 |
| 对应后缀加 `.json` | 同样的可移植数据，图片内嵌 data URL |
| `.yahari-sounds.json` | 合成声音参数及隐藏状态 |
| `.yahari` | 整部作品、场景、人物绑定、自有素材副本、内置调整及声音设置 |

导入先预览数量、作者、来源与许可，再确认写入素材库。相同包 ID 默认建立新副本，也可明确选择替换本机原件；不会自动替换当前作品。分享某一包无需带上剧本或内置图集。

## 数据与模块

- `packages/asset-library/`：适配器无关的角色/场景 DTO、格式校验、归档、作品自有素材收录和现有演出格式转换。
- `apps/editor/src/asset-workspace.ts`：独立素材界面，通过 snapshot / prepare / use / visibility / audio 接口连接对话编辑。
- `apps/editor/src/builtin-assets.ts`：内置目录、图集裁切、来源记录与作品内置调整合并。
- `apps/editor/src/asset-image-policy.ts`：上传与裁切尺寸限制、默认压缩常量及页面说明。
- `apps/editor/src/builtin-audio-assets.ts`、`asset-audio-workspace.ts`：声音参数验证、作品设置及声音管理界面。
- `apps/editor/src/asset-library-store.ts`：独立 IndexedDB `yahari:asset-library:v1`，数据库版本 2，packs、images 与 settings；升级保留旧数据，SHA-256 Blob 去重、事务保存和未引用图片回收。
- `packages/project-io/`：作品和素材包共用的有界 ZIP STORE 容器。

包文件格式为 `yahari-asset-pack` 1.0，容器含 `asset-pack.json` 与图片字节。独立 DTO 不包含脚本或 AI 凭据；图片完整携带，可选 stage / foreground 保存舞台图层，origin 记录内置来源。原创素材没有舞台背景时，转入当前 Courtroom 演出格式附加程序绘制的中性舞台。

内置调整用于作品时汇总为一个自有包，只嵌入改动图片和新增动作，保留历史人物绑定及角色 / 动作 / 场景引用。共享的内置舞台图片调整会影响作品中使用同一资源的机位。作品仍声明原内置包版本依赖；独立导出角色或场景时携带裁切后的全部所需图片。

当前单包最多 50 个角色或场景、每角色 50 个动作、99 张图片；图片 data URL 合计最多 20,000,000 字符，文件最大 32 MB。ZIP 校验路径、唯一性、CRC、图片引用及额外条目；不接受 SVG 或普通压缩 ZIP。作品格式仍最多使用 4 个自有包，每包 100 张图片。声音 JSON 包最大 250 KB、80 个预设、每预设 32 个音符。完整主题包的音频文件、布局、依赖和大型素材安装仍待实现。

## 内置素材验收（2026-10-13）

浏览器已验证旧版本数据库升级保留原角色和图片；24 / 192 / 23 清单、逐动作裁切；修改默认动作、增加动作和前景，应用后保持原人物绑定，只嵌入改动图片；移除 / 刷新 / 恢复、恢复默认保留作品版本、新动作排练；声音编辑 / Ctrl+S / 新增 / 试听 / 移除 / 恢复 / JSON 导入导出。真实下载角色 / 场景 / 声音 / 作品文件，在新浏览器导入后仍可排练，保留来源和前景。375px 页面与说明弹窗无横向溢出。完整检查 147 项测试、58 个浏览器模块通过；其余验收结果见 [当前进度](当前进度.md)。

## 图片接口与此前模拟验收（2026-10-12）

真实绘图入口沿用 OpenRouter 的 [`/api/v1/images` 与绘图模型目录](https://openrouter.ai/docs/guides/overview/multimodal/image-generation)。按模型目录的 `supported_parameters` 决定是否发送图片格式及透明底参数；参考图使用 `input_references`。没有 `media_type` 时识别常见 PNG/JPEG/WebP 的编码前缀。

OpenRouter 当前绘图需要可用余额；免费文本模型不能代替绘图模型。[官方绘图说明](https://openrouter.ai/blog/tutorials/image-generation-models/) 当前明确没有免费绘图模型。已连接的 ChatGPT 订阅通道目前用于文本，不能把它作为图片接口。

用户选择本轮使用模拟接口：浏览器拦截 OpenRouter 模型目录和图片 POST，返回程序绘制的原创测试图。没有调用实际绘图模型，也没有使用真实 Key 或产生绘图费用。这验证数据与界面流程，不验证实际绘图质量、人物一致性或真实提供商的模型支持。

已验证：

1. 角色立绘生成预览 → 参考立绘生成“惊讶” → 独立保存；另生成场景背景。
2. 原件刷新恢复；真实下载角色包、场景包；在新浏览器导入。
3. 取消导入、损坏包拒绝、相同 ID 保留副本、包资料 Ctrl+S。
4. 导入人物使用“惊讶”动作写台词，在导入书店场景排练，导出整部作品；解包后结构、图片、动作与编译有效，未携带凭据。
5. 手动替换姿态图片保持立绘及动作 ID；取消延迟生成保留旧预览；模拟 HTTP 402 保留已有图片。
6. 删除素材库原件后作品副本仍可排练；375px 宽度编辑界面无横向溢出。

可直接导入的两份测试包见 [模拟绘图素材](../examples/mock-image-assets/README.md)。
