更新：2026-10-14。本地声音库提供 **35 个原创音效、16 段原创循环配乐**。用途划分参考 [CAPCOM 官方原声曲目目录](https://store.steampowered.com/app/1335140/Phoenix_Wright_Ace_Attorney_Original_Soundtrack/) 中的开庭、询问、推理、追击、调查、追忆和胜诉等演出阶段；旋律与音效由本项目重新编写。

声音页按类型与用途筛选，也能搜索名称或使用说明。列表直接选中声音，设置栏保持可见；支持名称、用途、使用说明、音色、相对音量与速度。试听当前设置可以听到未保存的改动；保存后点击「应用到当前作品」，该版本随 `.yahari` 与独立 HTML 携带。停止按钮在试听期间出现。

方波承担主旋律，三角波承担柔和低音，噪声承担打击与摩擦；配乐结合旋律、低音和节拍，当前为 1.6–4 秒短循环。素材试听播放一次，演出音乐循环；读者的声音开关会在跨场景和恢复阅读时保留。对白低 / 高音提示现已自动随文字逐字播放，不再需要逐句插入音效动作。

素材库和演出共用 `chip-audio.ts`：12kHz 单声道、8Bit 阶梯采样，保留音符时间、音量和每个音符的音色。旧正弦 / 锯齿波参数仍可读取。音量零保持静音，切换音乐、关闭声音和退出预览会停止已排队的声音。

「下载 WAV」导出所选当前设置的 8-bit PCM 文件；JSON 声音包保存可继续编辑的参数、分类和使用说明。当前尚未提供音频文件上传。参数包最大 500 KB，最多 80 个声音，每个最多 32 个音符。已有作品版本保留；应用时会检查剧本引用，防止覆盖掉正在使用的声音。

旧内置资源 ID 保留。升级完整旧声音库时补入新增预设，保留旧调整与移除状态，并遵守 80 项上限。音符源定义及原创短句在 `scripts/build-chip-audio.mjs`；运行它会重建 `catalog.json` 的声音部分，再运行常规构建。

验证覆盖 51 个声音的确定采样、互不相同的结果、8Bit 数值与 WAV 头、分类/混合声部的作品包往返、旧设置分类推断与声音停止。真实 Edge 验证了分类筛选、试听的 WebAudio 缓冲、改名/变速/保存/应用、真实 WAV 与作品包下载、手机布局和断网 HTML 播放。

## 人物喊话与动作声音

声音页新增 17 段日语人物喊话，来自 Court Records，录音权利归 CAPCOM / 相应权利方。这些录音保留原有声音；一般音效、文字音与配乐继续使用原创 8Bit 合成。选择「声音类型：人物喊话」可试听与下载，在对话里点击动作可绑定、静音或设置人物默认。详情、来源和验证见 [动作音效](ACTION_SOUNDS.md)。

## 默认文字音

每句台词默认播放「对白 · 低音」的短脉冲，旁白也适用。点台词左侧的人物头像，可修改作品默认文字音，以及当前人物的默认文字音。台词上方的「本句文字音」可以选择其他声音或静音；优先级是本句设置、人物默认、作品默认。选择「跟随默认」会恢复继承，静音则是明确覆盖。

声音跟随完整字素逐字触发，忽略空白和标点；等待、准备图像和补全全文不会补播跳过的字符。每个声音的 PCM 缓冲只生成一次，连续字音至少间隔 30 ms，不会积压播放。可用于文字音的素材必须是不循环、最长 80 ms 的短音效，避免把配乐或长提示音反复播放；默认低 / 高音均为 24 ms。已经绑定的文字音不能从作品声音设置里直接移除或改成长音。

排练和新读者首次尝试开启声音，浏览器限制自动播放时仍可点击声音按钮开启。关闭后会保留选择，包括跨场景和恢复阅读。旧作品未设置文字音时自动获得默认声音，旧声音参数包缺少低 / 高音时会补齐。

持久化使用现有扩展字段：`manifest.projectSettings.typingSound`、`cast[].overrides.typingSound` 和对白的 `metadata.typingSound`。字段缺省表示继承，`null` 表示静音，资源引用为 `{ packId, id }`。无需升级作品文件版本；编辑器和独立 HTML 采用同一编译及播放逻辑。
