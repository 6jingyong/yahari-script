## 现在是什么阶段

已经是能完成创作、排练、保存和分享的本地原型。独立作品管理以流程图为唯一视图，作品 / 章节 / 场景设置常驻；互动、分支 / 跳转 / 结局是可选功能，选项按钮直接显示在演出画面内。独立阅读页和离线 HTML 导出已接入。除了内置法庭案例，也能用原创角色和自有背景写普通对话小剧场。接下来以普通创作和阅读体验为主，逐步完善原创素材绑定与中性演出适配器。

默认文字音已经接入逐字播放：作品默认、人物默认、本句覆盖依次生效，旁白也可使用；支持静音。点人物头像设置人物默认，每条台词的「本句文字音」可切换。排练与离线阅读首次尝试开启声音，保留用户之后的关闭选择；空白、标点、等待和补全全文不会连响。设置随作品保存和导出。

新增 17 段日语人物喊话（9 位人物），异议动作自动匹配视觉人物，拍桌搭配 8Bit 音效。动作详情支持单次绑定 / 静音与人物默认、试听、撤销；喊话后继续文字，快进、重播和声音关闭会停止录音。素材库可以浏览 / 下载，独立 HTML 可断网播放。[使用与来源](ACTION_SOUNDS.md)。
