# 作品管理与分支剧本

更新：2026-10-14。GitHub Pages、GPT Sites 和本地版均已更新；以作品、章节和场景管理为主，互动与分支是可选功能。

## 作者怎么用

顶栏「作品管理」取代旧目录。唯一主视图是故事流程图，展示场景背景、实际连接、选择、汇合与结尾，不按人物分栏，也不显示对白。作品资料、章节设置和所选场景的资料 / 后续走向常驻页面，不需要点击标签打开。普通故事默认按章节顺序阅读，不需要建立分支。

点击场景节点直接更新右侧设置，管理名称、摘要、章节、背景和继续方式。「编辑对话」进入所选场景，当前管理的场景可以与当前写作的场景不同。移除了场景卡片视图、内层标签、重复标题、多个保存按钮和重复编辑入口。不再提供人物线路或时间标注设置；旧文件中的相关元数据保留，但不影响展示或播放。

流程图支持拖动、滚动、缩放和场景名称 / 摘要搜索；搜索后按 Enter 选择第一个匹配场景。左侧「查看章节」筛选路线并显示对应章节资料；章节或场景的顺序可直接调整。手机端流程图位于上方，作品 / 章节 / 场景设置按顺序排列在下方，使用正常页面滚动。

场景末尾有四种继续方式：按章节顺序继续、跳到指定场景、显示 2–8 个互动选项、结束故事。新增选项默认填入章节顺序中的下一场，不需要分别建立分支；多个选项可以继续同一个后续场景，并保留各自的选择记录。需要分支时再指定不同场景；不同路线也可以汇合。选项保存的是实际场景 ID，之后重排章节不会自动改写已设置的目标；最后一场没有默认后续场景，添加选项时需指定目标。实际路线问题直接出现在图下方；没有问题时不显示检查区域。循环路线允许存在，并提示没有出口的循环。缺少目标、重复选项 ID 或无效结构不能保存、导入或游玩。

顶栏「保存」或 Ctrl+S 一次保存页面中所有已修改的表单。新建、导入、AI 设置、阅读与 HTML 导出入口常驻顶栏；作品文件、恢复点和示例集中在「作品与文件」。阅读、导出和切换作品前保存有效修改；离开未保存的管理页可选择取消。结构修改会建立恢复点，保留最近 8 个。开头场景不显示删除操作；有显式连接指向的场景必须先改好目标才能删除。

「从开头阅读」打开独立读者页面，不需要进入编辑器。逐句读完后点击「显示选项」或画面，选择按钮直接出现在当前演出画面内；选中后继续播放。选择界面保留场景背景和人物，可用键盘操作，关闭后再打开会恢复待选状态。也可以返回上一场重新选择、查看已走过的路线或从头开始。进度按作品内容保存在当前浏览器，改写作品后使用新的进度。回退会删除被撤销的选择。

## 分享

- `.yahari` / JSON：用于继续编辑。带有分支的作品文件版本为 **0.9**；仍能读取旧版 0.7 / 0.8。旧编辑器拒绝 0.9，避免误把分支作品当作线性剧本。
- 「导出 HTML」：把播放器、剧情、演出所需图片和合成声音定义放进一个文件。直接在浏览器打开即可离线阅读和选择，无需安装 Node.js、启动服务器或提供 AI 连接。
- 独立播放器入口：`http://127.0.0.1:4173/apps/player/`，可打开作品文件；静态构建也包含这个页面。

示例《雨停之前》包含 2 章、6 场、19 句对白、两次选择和两个结局。作者入口「作品与文件 → 分支体验示例」会保留当前作品并建立新作品。可直接打开 [离线 HTML](../examples/branching-story/雨停之前.html)，或导入 [可编辑作品包](../examples/branching-story/雨停之前.yahari)。源码见 [fixture.ts](../examples/branching-story/fixture.ts)。

## 人物绑定

「故事转剧本」先识别原故事人物，丢弃模型建议的内置形象映射，再让作者逐个选择内置人物。界面显示头像和“故事姓名 → 内置人物”；对白保留故事姓名，内置人物提供形象和动作。少选一人就不能确认；全部选择并明确确认后才建立场景计划。共用同一形象时会显示提醒。

确认记录绑定到人物 ID、故事姓名和素材 ID。修改姓名或素材会要求重新确认；旧草稿仅保存的 `bindingsConfirmed: true` 不足以跳过这个步骤。角色、动作和背景仍由既有素材校验与编译流程检查。

## 实现边界与验证

`ProjectManifest.flow` 保存剧情路线；章节顺序提供未设置出口的默认路线。Core 负责形状和引用校验，`packages/narrative` 管理路线历史，演出仍由 Courtroom 编译器和播放器执行。独立 HTML 使用内嵌模块映射与图片，不加载编辑器状态或 AI 连接配置。

最新检查：174 项测试、67 个浏览器模块、素材和已有真实示例检查通过；静态构建成功。Edge 实测唯一流程图、常驻设置、Ctrl+S / 刷新、35 个音效与 16 段配乐的分类 / 试听 / 编辑 / 应用 / 文件导出、375px 布局，以及最新 HTML 断网选择并到达结局。此前同目标选项、回退重选、人物手动绑定与恢复读取的验证保留。本轮没有发送模型请求。声音说明见 [8Bit 声音](8BIT_AUDIO.md)。

磁盘文件选择器使用模拟句柄验证：选择文件后，管理页 Ctrl+S 写入更新过的 0.9 路线。真实下载文件另经新浏览器导入和离线游玩验证。`scripts/check-branch-example.mjs` 随常规检查核对实际导出的两个示例文件与源码一致。

第一版分支位于场景末尾；要在一段对白中安排选择，可以把它拆成前后两个场景。目前还没有证据条件、隐藏选项、数值变量或 AI 分支规划。场景内的背景/音乐继续按各场演出指令处理。

互动与分支作为创作工具的可选辅助，不要求人物线路、条件变量或跨人物解锁。
