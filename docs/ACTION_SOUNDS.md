# 动作音效与人物喊话

更新：2026-10-14。本地新版有 17 段日语喊话，与此前的 35 个原创 8Bit 音效、16 段配乐并存。录音来自 [Court Records 音频目录](https://www.court-records.net/audio.htm)，覆盖成步堂、御剑、千寻、王泥喜、狩魔冥、狩魔豪、戈多、牙琉雾人和牙琉响也；其中成步堂、御剑、千寻、王泥喜各有「異議あり！」「待った！」「くらえ！」，其他人物有异议喊话。来源未授予额外使用许可，录音权利归 CAPCOM / 相应权利方，详见 [素材权利记录](../THIRD_PARTY_ASSETS.md)。

## 使用

- 内置人物的「异议」动作默认播放该人物的日语喊话。匹配依据是作者选择的视觉人物，保留故事角色名字；不会按故事姓名猜测人物。没有可用喊话的人物使用原来的原创 8Bit 异议音效。拍桌动作默认搭配 8Bit 拍桌声。
- 在对话里点击动作，右侧「动作详情」的 **动作声音** 可选择自动、人物喊话、8Bit 音效或无音效 / 静音；可以试听。设置跟随这一个动作保存，支持撤销。
- **设为这个人物的同类动作默认** 将当前选择应用到该作品人物的同类动作。单独设置过声音的动作仍保留自己的选择；自动表示恢复内置默认。
- **素材管理 → 声音 → 声音类型：人物喊话** 浏览和试听全部录音，也可下载原始 MP3 / WAV。来源常驻侧栏。这里的录音为内置素材，8Bit 参数包仍用于编辑 / 导入程序化音效。
- 声音总开关同时控制文字音、动作音效、喊话和配乐。录音预解码后在动作发生时播放；喊话结束才显示后面的文字。直接插入喊话音效也会等待录音结束。快进不会排队补播跳过的喊话，重播 / 返回会停止上一段喊话，静音和关闭演出立即停止录音。

## 保存与导出

单次动作使用 `token.metadata.sound`，人物默认使用 `cast[].overrides.actionSounds`，键为 `pose:<id>` / `reaction:<id>`。缺省表示继承，`null` 表示静音，资源引用使用 `{ packId, id }`。普通人物名和动作主体绑定保持原样；显式指定执行人物的动作使用该人物的声音。

编译按顺序输出动作、绑定音效和录音等待。声音设置随 `.yahari` 保存；当前内置录音通过内置素材包提供。独立 HTML 将录音字节包含在运行时模块中，不访问外部音频站点，断网也能播放。缺失或已移除的显式绑定会报错，声音库应用时保护仍被动作引用的音效。

原始下载文件位于 `content-packs/courtroom-demo/assets/voices/`；[voice-clips.json](../content-packs/courtroom-demo/voice-clips.json) 记录逐项来源、语言、人物、格式、时长、字节数与 SHA-256。`scripts/fetch-courtroom-voices.mjs` 可复用已有文件并下载公开音频，常规构建只读取本地文件，不联网。尚未取得亚内的录音，当前继续使用 8Bit 后备音。

## 验证

188 项测试 / 71 个浏览器模块及 17 个音频的来源、哈希、嵌入字节检查通过。真实 Edge 验证所有录音可解码且各不相同、人物匹配、先动作 / 喊话后文字、快进、重播、静音、单次覆盖、人物默认、撤销、声音库、375px 设置与离线 HTML。既有逐字音、声音素材和分支选择继续回归。
