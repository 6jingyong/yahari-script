# Q 版素材第一轮

现有资源 ID 和剧本动作保持兼容。15 名角色有常态、强调动作、情绪反应的基础透明立绘；15 个场景使用同组 Q 版环境插画；辩护席、检方席和证人席有独立透明前景。成步堂、真宵、御剑、裁判长、糸锯、狩魔冥、狩魔豪、大泽木夏美、矢张、灰根高太郎、绫里千寻、王泥喜、牙琉响也和宝月茜已有独立动作图；其他角色的相近动作暂时共用三种基础立绘。后续逐项补齐专属姿势，避免仅换标签但画面不变。狩魔冥是可选检方角色，没有加入原有案例的默认出场阵容。

源图在 `art-source/`。独立动作图、可选的独立头像及 4×2 格顺序由 `action-sheets.json` 声明；动作页可以是 PNG，也可以是带明确宽高的仓库原创 SVG。新增或修改动作图时运行 `python scripts/install_action_sheets.py`，再运行 `python scripts/map-chibi-art.py` 更新资源帧与哈希，最后执行 `npm run check`。只有修改基础角色/场景拼图时才运行 `python scripts/build-chibi-art.py` 全量切图。正式演出以 `catalog.json` 中的稳定 Resource ID 为准，新增动作先在角色能力中声明，再绑定资源，不直接靠文件名推断能力。

生成提示词概述：透明底、统一二头身的法庭角色表情图；暖木色与青绿色阴影的法庭和调查场景；法庭席位的透明前景。每张角色图统一为 512×384 的演出画布，场景和前景为 768×576。生成方式为内置 imagegen，切图仅做裁剪、缩放和透明画布布局。
