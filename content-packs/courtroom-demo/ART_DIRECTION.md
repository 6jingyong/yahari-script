# Q 版素材第一轮

现有资源 ID 和剧本动作保持兼容。14 名角色各有常态、强调动作、情绪反应三张透明立绘；15 个场景全部改为同一组 Q 版环境插画；辩护席、检方席和证人席增加独立透明前景。角色动作共 66 项，其中相近动作暂时共用三种基础立绘。这是后续最明确的扩充清单：逐项绘制 `think`、`desk`、`bow`、`sad` 等专属姿势，避免仅换标签但画面不变。

源图在 `art-source/`。修改源图后运行 `python scripts/build-chibi-art.py` 切图，再运行 `python scripts/map-chibi-art.py` 更新目录和哈希，最后执行 `npm run check`。正式演出以 `catalog.json` 中的稳定 Resource ID 为准，新增动作时先在角色能力中声明，再绑定资源，不直接靠文件名推断能力。

生成提示词概述：透明底、统一二头身的法庭角色表情图；暖木色与青绿色阴影的法庭和调查场景；法庭席位的透明前景。每张角色图统一为 512×384 的演出画布，场景和前景为 768×576。生成方式为内置 imagegen，切图仅做裁剪、缩放和透明画布布局。
