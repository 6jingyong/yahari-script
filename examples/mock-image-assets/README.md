# 模拟绘图素材

这两份包由浏览器模拟 OpenRouter 响应后，从真实素材界面导出。图片为程序绘制的几何测试图，未调用 LLM 或绘图模型；用于验证流程，不代表 AI 画质。

- `characters.yahari-characters`：林羽，人物设定与标签，立绘、“平常”姿态和“惊讶”表情。
- `scenes.yahari-scenes`：午后书店，背景及场景说明。

在本地编辑器顶栏打开 **角色与场景 → 导入素材包**，分别选择文件、检查预览并确认。角色可加入当前作品，背景可应用到当前场景，然后返回对话编辑写台词、添加动作并排练。

测试包仅含这些程序绘制图片和资料，不包含内置角色、图集、剧本或 AI 连接。来源与许可记录在包内，测试图片声明 CC0-1.0；此声明不涉及内置法庭角色或任何第三方 IP。
