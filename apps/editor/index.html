打开设置后检查本地账户服务。

登录仅在本地版提供。连接保存在本机，Windows 下由当前用户加密保护；不会写入作品或导出文件。此通道暂不支持角色图片生成。

OpenRouter API

OpenRouter 连接供故事生成和角色图片生成共用。免费模型与收费模型由你自行选择。

密钥只保存在此浏览器的网站数据中，不进入作品或导出文件。共用设备可取消勾选；清除浏览器网站数据也会移除连接。
