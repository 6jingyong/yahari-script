矢张剧本 · 使用说明

体验分支故事：双击 examples/branching-story/雨停之前.html，用浏览器直接打开即可离线游玩，不需要安装软件。

创作、修改和阅读可以直接打开两个新版在线地址：
GitHub：https://6jingyong.github.io/yahari-script/apps/editor/
GPT 站点：https://yahari-script-qyc.qyc001.chatgpt.site/apps/editor/
两站均已更新作品管理、分支、素材库、逐字音和人物喊话，支持 0.9 作品。各站点 / 浏览器的草稿独立保存；通过 .yahari 作品包迁移。下面也可运行本地版本。

如果想运行文件夹里的本地版本（Windows）：
1. 安装 Node.js 22.6 或更新版本：https://nodejs.org/
2. 双击「双击启动本地版.cmd」。第一次启动需要联网安装依赖。
3. 等浏览器自动打开。使用期间保持弹出的命令窗口开启；关闭窗口就会停止本地服务。
4. 本地地址固定为 http://127.0.0.1:4173/apps/editor/ ，以便下次启动仍能读取浏览器草稿。重复双击会自动接替本项目已运行的新版服务；遇到旧版服务会直接打开它并使用刚构建的文件。只有其他程序占用这个端口时，才需要先关闭该程序。

顶栏有「作品管理」「对话编辑」「素材管理」。作品管理只保留故事流程图，不显示对白或人物线路；作品、章节、场景资料和继续方式直接常驻。点节点选择场景，「编辑对话」开始写台词。默认按章节顺序阅读，互动选项可继续同一场景或形成分支；阅读时直接点击演出画面内的按钮。顶栏保存或 Ctrl+S 一次保存全部资料。

对话默认带有随文字逐字出现的「哒哒哒」8Bit 文字音。点击台词左侧的人物头像，可以设置作品默认和该人物的默认文字音；台词上方的「本句文字音」可单独切换或静音。排练和离线阅读首次尝试开启声音，可用右上角声音开关关闭，后续会记住你的选择。声音设置随作品和 HTML 保存。

异议动作现在会自动播放你所选内置人物的日语喊话。点击对话中的动作，在「动作详情 → 动作声音」里切换喊话、8Bit 音效或静音，也能设为该人物的同类动作默认。素材管理的声音页选择「人物喊话」即可试听、下载全部录音；导出的 HTML 可以离线播放。

作品保存在当前浏览器。换电脑、换浏览器或分享可编辑作品时，在「作品与文件」中点击「下载 .yahari」，把下载的 .yahari 作品包发给对方；对方用「导入」打开。只想让对方阅读和选择，点击「导出 HTML」，把文件发给对方用浏览器打开即可。清除浏览器数据前请导出备份。旧 JSON 文件仍可导入。

在线版和本地版均使用「作品管理 → 作品与文件」管理多个浏览器内作品。对白会自动保存；管理页的资料与后续走向统一使用顶栏保存或 Ctrl+S。「保存」建立恢复点，最多保留 8 个。导出默认是包含自有图片的 .yahari 作品包，也可导出 JSON。导入先显示预览，确认后打开，不会删除之前的本机作品。

「保存到文件…」可选择磁盘文件；本次页面中 Ctrl+S 会继续更新它。不支持文件选择器的浏览器直接下载作品包。刷新后重新选择文件位置。三份 OpenRouter 生成的示例在 examples/openrouter-scripts/ 下，均可导入。

「素材管理」可以创建原创角色、上传立绘和动作，也可以创建背景、上传场景图片。保存后选入作品，图片会随作品导出，对方不需要另找图片。

「AI 连接设置」填写自己的 OpenRouter API Key，可勾选记住在此浏览器；故事生成和原创角色的 AI 立绘入口共用连接，并提供对应模型列表。取消勾选只在本页使用，「忘记此设备」移除已存连接。普通编辑、排练和游玩不需要 Key。图片生成与收费模型按平台规则扣费；本地版还提供 ChatGPT 账号登录和文本生成通道。

「故事转剧本」先识别人物，再由你逐个选择内置人物作为演出形象。界面显示“故事姓名 → 内置人物”；全部确认后才生成场景。对白保留故事姓名，内置人物提供形象和动作，不会按名字自动匹配。

开发进度见 docs/当前进度.md。本地更新在推送发布之前，不会自动出现在在线版。
